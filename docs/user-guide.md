## 4. Общие сведения о системе

### 4.1. Полное наименование системы и ее условное обозначение
Полное наименование: Система управления правами доступа и учетными записями пользователей в корпоративных информационных системах.  
Условное обозначение: СУПД.  
Регистрационный номер: 000.205.000.000.

### 4.2. Назначение системы
Система предназначена для автоматизации процессов управления доступами и учетными записями в рамках бизнес-процессов, включая прием на работу, перемещение, увольнение, изменение данных, продление трудовой деятельности, разблокировку учетных записей, назначение/отзыв ролей, создание/изменение/удаление ресурсов, выдачу ключей защиты информации, согласование и исполнение заявок, ресертификацию доступов.

Цели системы:
- Сокращение времени предоставления доступа (базовый доступ для новых сотрудников в течение 1 рабочего дня, дополнительный — в течение 2 рабочих дней).
- Снижение рисков безопасности за счет автоматизации проверок и аудита.
- Автоматизация труда, уход от бумажного документооборота, использование электронного документооборота.
- Создание единого справочника пользователей, ролей и ресурсов.
- Обеспечение юридической значимости с соблюдением законодательства.

### 4.3. Функциональный состав системы
Система включает среды тестирования, разработки и продуктивную среду с подсистемами серверов приложений, коннекторов, баз данных, веб-серверов, интеграционного обмена и отправки уведомлений.

### 4.4. Основные элементы интерфейса
Пользовательский интерфейс разделен на три типа: защищенный для работы с автоматизированными рабочими местами, защищенный для мобильных устройств (только согласование), открытый для ограниченного функционала.  
Доступ к защищенному интерфейсу требует средств защиты информации. Открытый интерфейс доступен всем в периметре сети.  
Мобильная версия поддерживает согласование заявок в браузерах для iOS и Android, доступна только с корпоративных устройств.  
Система не предусматривает печать документов на бумаге.

## 5. Аутентификация пользователя в системе

### 5.1. Аутентификация в версии для автоматизированных рабочих мест
Для входа:
- Установите подключение с использованием средств защиты (для защищенного интерфейса).
- Запустите систему через ярлык или адрес в браузере.
- При первичном входе подтвердите ознакомление с нормативными документами, установив флаг и нажав кнопку подтверждения.  
После входа отображается главная страница. Уведомление об ознакомлении отправляется руководителю.

### 5.2. Аутентификация в мобильной версии
Для входа:
- Запустите через ярлык или адрес.
- Введите логин и пароль, нажмите "Войти".  
При ошибке отображается уведомление.  
Для выхода: нажмите значок рядом с логином, выберите "Выйти".

## 6. Описание интерфейса

### 6.1. Открытый интерфейс
Элементы:
- Логотип.
- Главное меню (боковая панель, сворачиваемая).
- Меню быстрого доступа: запрос доступов для себя, просмотр своих доступов, поддержка.
- Раздел отправленных заявок (первые пять).
- Кнопки перехода к полным спискам, выхода.
- ФИО пользователя для перехода в карточку.  
Доступны: запрос доступов для себя (ограниченный перечень), просмотр/отмена своих заявок, информация о себе и системе.

### 6.2. Защищенный интерфейс
Элементы:
- Логотип.
- Главное меню (боковая панель).
- Меню быстрого доступа: запрос доступов для себя/других, отзыв доступов, просмотр своих доступов, делегирования, поддержка.
- Разделы отправленных и входящих заявок (первые пять).
- Кнопки перехода к полным спискам, выхода.
- ФИО пользователя для перехода в карточку.

### 6.3. Главное меню
В открытом интерфейсе: Заявки (работа с заявками), О системе (информация, лицензия).  
В защищенном: Заявки, Управление (пользователи, роли, ресурсы, записи, нарушения; зависит от роли), Администрирование (операции взаимодействия), Отчеты (статистика; зависит от роли), О системе.

### 6.4. Мобильная версия
Главная страница: перечень входящих заявок в виде блоков. Непрочитанные выделены. Функции: просмотр/согласование/отклонение заявок для согласующих.

## 7. Порядок использования функциональных блоков системы
Доступные функции зависят от роли: Пользователь, Линейный руководитель, Владелец роли, Владелец ресурса, Владелец системы, Согласующий от безопасности, Контроль безопасности, Администратор системы, Работник по учету персонала, Отдел ИТ.

### 7.1. Функции пользователя в открытом интерфейсе
- Создание заявки на доступы для себя: выберите доступы, проверьте, добавьте комментарий.
- Просмотр заявок: ожидающие отправки, отправленные, завершенные.
- Отмена заявок: выберите заявку, подтвердите с комментарием.

### 7.2. Функции пользователя в защищенном интерфейсе
Просмотр/редактирование информации:
- Карточка пользователя: вкладки с данными, трудоустройствами, доступами, записями, делегатами, делегированиями, историей.
- Трудоустройства: просмотр/добавление.
- Доступы: просмотр, фильтрация, сортировка, запрос дополнительных.
- Учетные записи: просмотр, сортировка, смена пароля.
- Делегаты/делегирования: просмотр, добавление/редактирование/удаление.
- История изменений: просмотр событий.

Работа с заявками:
- Просмотр: все, входящие (ожидающие/делегированные/обработанные), отправленные (активные/завершенные).
- Создание: для себя/других, изменение срока, отзыв, пересмотр, удаление ресурса.
- Согласование: в версии для рабочих мест или мобильной.

Построение отчетов: зависит от роли.

### 7.3. Функции линейного руководителя
Включает функции пользователя плюс:
- Просмотр/редактирование карточек подчиненных.
- Просмотр списка пользователей в подразделении.
- Согласование заявок по подчиненным.
- Построение отчетов: список пользователей по подразделениям, перечень заявок с согласующим, список заявок по критериям.

### 7.4. Функции владельца роли
Включает функции пользователя плюс:
- Просмотр списка пользователей роли.
- Просмотр/редактирование карточки роли.
- Создание заявок на отзыв/пересмотр доступов через карточку роли.
- Построение отчетов: список ролей по владельцу, список пользователей по роли, карточка роли, история изменения роли, перечень заявок с согласующим, список заявок по критериям.

### 7.5. Функции владельца информационного ресурса
Включает функции пользователя плюс:
- Просмотр списка пользователей ресурса.
- Просмотр/редактирование карточки ресурса.
- Создание заявок на отзыв/пересмотр/удаление ресурса.
- Построение отчетов: список ресурсов по владельцу, список пользователей по ресурсу, карточка ресурса, история изменения доступа к ресурсу, перечень заявок с согласующим, список заявок по критериям.

### 7.6. Функции владельца информационной системы
Включает функции пользователя плюс:
- Просмотр списка пользователей системы.
- Просмотр карточки системы.
- Расширенный поиск пользователей.
- Создание заявок на отзыв/пересмотр доступов через карточку системы.
- Построение отчетов: история изменения доступа к ресурсу, карточка ресурса, доступ к системам, перечень заявок с согласующим, список заявок по критериям, список пользователей по ресурсу.

### 7.7. Функции согласующего от информационной безопасности
Включает функции пользователя плюс:
- Просмотр списка пользователей всех систем.
- Просмотр организационной структуры.
- Просмотр матрицы доступа.
- Анализ ролевой модели.
- Аудит соответствия доступов.
- Блокировка/разблокировка учетных записей.
- Создание заявок на отзыв/пересмотр через карточки.
- Построение отчетов: все доступные, плюс статистика назначения ролей, учет времени, история обращений, соответствие доступов, методика расчета активных пользователей, аудит событий, история кадровых данных/полномочий, карточка пользователя на дату, согласованные заявки, фактический доступ, несвязанные записи, проверка на конфликты.

### 7.8. Функции контроля безопасности
Включает функции пользователя плюс:
- Просмотр карточек всех пользователей.
- Просмотр списков ролей/ресурсов с пользователями.
- Просмотр истории заявок.
- Построение всех отчетов системы.

### 7.9. Функции администратора информационной системы
Включает функции пользователя плюс:
- Просмотр/редактирование карточки системы.
- Исполнение заявок: создание/изменение/удаление ресурсов, назначение/отзыв полномочий, смена контекста.
- Просмотр/редактирование ресурсов.
- Создание заявок на удаление ресурса.

### 7.10. Функции работника по учету персонала
Включает функции пользователя плюс:
- Просмотр/редактирование карточек пользователей в группе.
- Просмотр/редактирование организационной структуры (включая подрядчиков).
- Построение отчетов: список пользователей по подразделениям.

### 7.11. Функции отдела ИТ
Включает функции пользователя плюс:
- Просмотр заявок по системам.
- Просмотр списков ролей/карточек.
- Просмотр ресурсов.
- Построение отчетов: перечень заявок с согласующим, список заявок по критериям.

## 8. Описание работы в системе

### 8.1. Описание выполняемых функций
Система состоит из подсистем: взаимодействия с пользователями, хранения данных, взаимодействия с источниками, обработки задач, аудита, отчетности, управления заявками/уведомлениями/конфигурацией/объектами, электронной подписи, защиты.

| Подсистема | Основные функции |
|------------|------------------|
| Взаимодействия с пользователями | Аутентификация, интерфейс, запросы. |
| Хранения данных | Справочники пользователей, ролей, ресурсов. |
| Взаимодействия с источниками | Синхронизация, provisioning. |
| Обработки задач | Фоновые процессы, workflow. |
| Аудита | Логирование действий. |
| Формирования отчетности | Генерация отчетов по критериям. |
| Управления заявками | Создание, согласование, исполнение. |
| Уведомлений | Отправка оповещений. |
| Конфигурации | Настройка параметров. |
| Управления объектами | Жизненный цикл ролей/ресурсов. |
| Электронной подписи | Юридическая значимость. |
| Защиты информации | Шифрование, аутентификация. |

### 8.2. Типовые сценарии взаимодействия
- Вход: аутентификация, ознакомление.
- Просмотр: информация о себе/других, заявки.
- Изменения: редактирование данных.
- Заявки: создание на доступы/ресурсы/ресертификацию, отмена, исполнение, решение.
- Отчеты: построение по ролям.

- Изучите меню и роли.
- Практикуйте создание/согласование заявок.
- Используйте отчеты для анализа.
- Обратитесь в поддержку при вопросах.
